# 3. 좋아하는 것 칸 모양: 직사각형 → 하트

## 무엇을 바꿨나요?
좋아하는 것 3가지가 **위아래로 쌓인 직사각형 칸**이었는데, 이를 **가로로 나란히 놓인 하트 3개**로 바꿨어요.
하트 안에는 이모지와 글자가 가운데에 들어가 있어요.

- 수정한 파일: `index.html` (HTML, CSS 수정 / JavaScript는 그대로)
- 2번의 쿠키 효과는 그대로 동작해요. 이제 **쿠키 하트**를 누르면 쿠키가 커비 입으로 날아가요.

```
a (직사각형)                        b (하트)
┌──────────────────────────────┐
│ 🍪 새로운 과자 사먹기  눌러보세요 │      ♥        ♥        ♥
├──────────────────────────────┤     🍪       🧱       🌿
│ 🧱 블록 조립하기               │    새로운    블록     자연
├──────────────────────────────┤   과자사먹기  조립하기  구경하기
│ 🌿 자연 구경하기               │
└──────────────────────────────┘      🍪 쿠키 하트를 눌러보세요
```

---

## 변경 1. HTML: 각 칸에 하트 그림 넣기

### Before (a)
```html
<ul class="likes">
  <li class="clickable">
    <button type="button" class="like-btn" id="snackBtn">
      <span class="emoji">🍪</span>새로운 과자 사먹기
      <span class="hint">눌러보세요 👆</span>
    </button>
  </li>
  <li><span class="emoji">🧱</span>블록 조립하기</li>
  <li><span class="emoji">🌿</span>자연 구경하기</li>
</ul>
```

### After (b)
```html
<ul class="likes">
  <li>
    <svg class="heart-bg" viewBox="0 0 100 92" preserveAspectRatio="none" aria-hidden="true">
      <path d="M50 88 C50 88 4 60 4 30 C4 15 15 4 29 4 C38 4 46 9 50 17 C54 9 62 4 71 4 C85 4 96 15 96 30 C96 60 50 88 50 88 Z" />
    </svg>
    <button type="button" class="like-content like-btn" id="snackBtn">
      <span class="emoji">🍪</span>새로운 과자 사먹기
    </button>
  </li>
  <li>
    <svg class="heart-bg" ...>(같은 하트)</svg>
    <div class="like-content"><span class="emoji">🧱</span>블록 조립하기</div>
  </li>
  <li>
    <svg class="heart-bg" ...>(같은 하트)</svg>
    <div class="like-content"><span class="emoji">🌿</span>자연 구경하기</div>
  </li>
</ul>
<p class="hint">🍪 쿠키 하트를 눌러보세요</p>
```

### 설명
- 각 칸(`<li>`)은 **두 겹**으로 만들었어요.
  1. 아래 겹: `<svg class="heart-bg">` → **하트 그림**
  2. 위 겹: `.like-content` → **이모지 + 글자**
- `<svg>`는 코드로 그림을 그리는 태그예요. `<path d="...">`의 좌표가 하트 윤곽선이에요.
  - `viewBox="0 0 100 92"`: 가로 100, 세로 92짜리 도화지에 하트를 그렸다는 뜻이에요.
  - `aria-hidden="true"`: 꾸밈용 그림이라 화면 낭독기가 읽지 않게 해요.
- 내용을 감싼 태그도 통일했어요. 쿠키는 눌러야 하니까 `<button>`, 나머지는 `<div>`에 똑같이 `like-content` 이름을 붙였어요.
- "눌러보세요" 안내는 하트 안에 넣기엔 공간이 좁아서, 목록 **아래로** 옮겼어요.

---

## 변경 2. CSS: 하트 색 변수

### Before (a)
없음

### After (b)
```css
:root {
  --heart: #ffe6ee;       /* 하트 안쪽 색 (연분홍) */
  --heart-line: #ffc4d6;  /* 하트 테두리 색 */
}
@media (prefers-color-scheme: dark) {
  :root {
    --heart: #3a2430;      /* 다크 모드용 */
    --heart-line: #5e3346;
  }
}
```

### 설명
- 하트에 어울리는 분홍색을 밝은 화면과 다크 모드에 각각 따로 정해 두었어요.

## 변경 3. CSS: 세로 목록 → 가로 하트 3개

### Before (a)
```css
.likes {
  list-style: none;
  display: grid;
  gap: 10px;
}

.likes li {
  display: flex;
  align-items: center;
  gap: 14px;
  padding: 14px 16px;
  border: 1px solid var(--line);
  border-radius: 14px;
  font-weight: 500;
  transition: transform 0.15s ease, border-color 0.15s ease;
}

.likes li:hover {
  transform: translateY(-2px);
  border-color: var(--accent);
}

.emoji {
  width: 40px;
  height: 40px;
  flex-shrink: 0;
  display: grid;
  place-items: center;
  font-size: 20px;
  background: var(--accent-soft);
  border-radius: 10px;
}

.likes li.clickable { padding: 0; }

.like-btn {
  all: unset;
  box-sizing: border-box;
  width: 100%;
  display: flex;
  align-items: center;
  gap: 14px;
  padding: 14px 16px;
  border-radius: 14px;
  cursor: pointer;
}

.like-btn:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }

.hint {
  margin-left: auto;
  font-size: 12px;
  color: var(--muted);
}
```

### After (b)
```css
/* 좋아하는 것: 하트 3개를 가로로 나란히 */
.likes {
  list-style: none;
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

/* 하트 한 칸: 가로:세로 = 100:92 (하트 그림 비율) */
.likes li {
  position: relative;
  min-width: 0;
  aspect-ratio: 100 / 92;
  font-weight: 500;
  transition: transform 0.15s ease;
}

.likes li:hover { transform: translateY(-3px); }

/* 하트 그림 (칸 크기에 맞춰 늘어나요) */
.heart-bg {
  position: absolute;
  inset: 0;
  width: 100%;
  height: 100%;
  overflow: visible;
}

.heart-bg path {
  fill: var(--heart);
  stroke: var(--heart-line);
  stroke-width: 1.5;
  vector-effect: non-scaling-stroke;
  transition: stroke 0.15s ease;
}

.likes li:hover .heart-bg path,
.likes li:focus-within .heart-bg path {
  stroke: var(--accent);
  stroke-width: 2;
}

/* 버튼 기본 모양 지우기 (.like-content보다 먼저 써야 위치 설정이 지워지지 않아요) */
.like-btn {
  all: unset;
  box-sizing: border-box;
  cursor: pointer;
}

/* 하트 안의 이모지 + 글자 (하트의 통통한 윗부분 가운데에 배치) */
.like-content {
  position: absolute;
  inset: 0;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: center;
  gap: 4px;
  padding: 8% 14% 24%;
  text-align: center;
  font-size: 14px;
  line-height: 1.35;
  word-break: keep-all;
}

.emoji { font-size: 26px; line-height: 1; }

.hint {
  margin-top: 12px;
  text-align: center;
  font-size: 12px;
  color: var(--muted);
}
```

### 설명
| 코드 | 하는 일 |
|---|---|
| `grid-template-columns: repeat(3, 1fr)` | 위아래로 쌓던 칸을 **같은 너비 3칸으로 가로 배치**해요. |
| `border`, `border-radius` → **삭제** | 직사각형 테두리를 없앴어요. 이제 모양은 하트 그림이 담당해요. |
| `aspect-ratio: 100 / 92` | 칸의 가로:세로 비율을 하트 그림과 똑같이 맞춰요. 화면이 넓든 좁든 **하트가 찌그러지지 않아요.** |
| `min-width: 0` | 글자가 길어도 칸이 옆으로 넘치지 않고 3칸이 화면 안에 들어오게 해요. |
| `position: relative` (칸) + `position: absolute; inset: 0` (하트·내용) | 하트 그림과 내용을 **같은 자리에 겹쳐 쌓는** 방법이에요. 칸이 기준이 되고, 두 겹이 칸에 꽉 맞게 붙어요. |
| `.heart-bg path { fill; stroke }` | 하트 안쪽은 `--heart` 색으로 칠하고, 테두리는 `--heart-line` 색으로 그려요. |
| `vector-effect: non-scaling-stroke` | 하트가 커지거나 작아져도 **테두리 두께는 그대로** 유지해요. |
| `li:hover`, `li:focus-within` | 마우스를 올리거나 키보드로 이동하면 하트 테두리가 **파란색**으로 바뀌고 살짝 떠올라요. (전에는 직사각형 테두리가 파래졌어요.) |
| `.like-content { flex-direction: column; ... }` | 이모지를 위에, 글자를 아래에 **세로로** 놓고 가운데 정렬해요. |
| `padding: 8% 14% 24%` | 하트는 아래쪽이 뾰족해서 내용이 들어갈 자리가 없어요. 아래 여백(24%)을 크게 줘서 내용을 **하트의 통통한 윗부분**으로 올렸어요. |
| `word-break: keep-all` | 줄이 바뀔 때 "사먹/기"처럼 단어 중간에서 끊기지 않게 해요. |
| `.emoji` | 네모 배경을 없애고 이모지만 크게(26px) 보여줘요. |
| `.like-btn`을 `.like-content`보다 **앞에** | `all: unset`은 "모든 스타일 초기화"라서, 뒤에 쓰면 `.like-content`의 위치 설정까지 지워버려요. 그래서 순서를 앞으로 옮겼어요. |
| `.hint` | 목록 아래 가운데에 작은 안내 문구로 보여줘요. |

## 변경 4. CSS: 모바일 화면 크기 조정

### Before (a)
```css
@media (max-width: 480px) {
  ...
  .intro { font-size: 16px; }
}
```

### After (b)
```css
@media (max-width: 480px) {
  ...
  .intro { font-size: 16px; }
  .likes { gap: 6px; }
  .like-content { font-size: 12px; padding: 6% 10% 24%; }
  .emoji { font-size: 22px; }
}
```

### 설명
- 폰 화면에서는 하트 하나가 약 95px 정도로 작아져요. 하트 사이 간격, 글자, 이모지를 조금씩 줄여서 3개가 한 줄에 들어가게 했어요.

---

## 결과
- **a:** 테두리가 있는 직사각형 칸 3개가 위아래로 쌓인 목록
- **b:** 연분홍 하트 3개가 가로로 나란히 있고, 하트마다 이모지와 글자가 가운데에 들어감
  - 마우스를 올리면 하트 테두리가 파래지며 살짝 떠오름
  - 쿠키 하트를 누르면 2번의 커비 쿠키 먹기 효과가 그대로 실행됨
