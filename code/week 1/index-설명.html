4. 배경색을 바꾸고 싶다면?

결론부터: 12줄과 25줄을 보면 돼요.

먼저, "배경"이 두 가지예요

카드 (흰색)
밝은 모드 · 노란 테두리 = 페이지 배경
카드 (짙은 남색)
다크 모드 · 노란 테두리 = 페이지 배경

카드 바깥의 넓은 바탕이 페이지 배경, 글자가 올라간 네모가 카드 배경이에요. 그리고 컴퓨터가 다크 모드인지 아닌지에 따라 다른 색이 쓰여요. 그래서 바꿀 줄이 두 개씩 있어요.

확인할 줄 (11~36줄, 색깔표)

11    :root {12      --bg: #f6f7fb;          ← 페이지 배경 (밝은 모드)13      --surface: #ffffff;       ← 카드 배경 (밝은 모드)14      --text: #1a1d29;       …22    }23    @media (prefers-color-scheme: dark) {   ← "다크 모드일 때는" 이라는 뜻24      :root {25        --bg: #111318;        ← 페이지 배경 (다크 모드)26        --surface: #1a1d25;     ← 카드 배경 (다크 모드)         …
줄무엇의 색?지금 색
12줄페이지 배경 · 밝은 모드#f6f7fb 아주 연한 회색
25줄페이지 배경 · 다크 모드#111318 거의 검정
13줄카드 배경 · 밝은 모드#ffffff 흰색
26줄카드 배경 · 다크 모드#1a1d25 짙은 남색

바꾸는 방법

  1. VS Code에서 index.html을 열고 12줄로 가요. (Ctrl+G를 누르고 12 입력)
  2. #f6f7fb 부분만 원하는 색 코드로 바꿔요. 예: 연한 분홍 #fff0f5. 앞의 --bg:와 끝의 ;는 그대로 둬야 해요.
  3. 다크 모드에서도 바꾸고 싶다면 25줄도 같은 방법으로 바꿔요. 다크 모드에는 어두운 색이 어울려요. 예: #1e1418
  4. 저장(Cmd+S)하고, 브라우저에서 새로고침(Cmd+R)하면 바로 보여요.
💡 왜 40줄(body)이 아니라 12줄을 바꾸나요?
42줄에는 background: var(--bg);라고 적혀 있어요. "색깔표의 --bg 칸에 적힌 색을 써라"라는 뜻이에요. 그래서 색깔표(12줄, 25줄)만 바꾸면 42줄은 손대지 않아도 자동으로 따라 바뀌어요. 색을 한곳에 모아 두면, 나중에 색을 바꿀 때 여기저기 찾아다닐 필요가 없어요.
🎨 지금 내 화면은 어떤 모드인가요?
보내주신 스크린샷은 어두운 화면이었으니 다크 모드예요. 그러면 눈에 보이는 배경은 25줄이에요. 12줄만 바꾸면 내 화면에서는 변화가 안 보일 수 있어요.
