# 1. 프로필 동그라미에 이미지 넣기

## 무엇을 바꿨나요?
페이지 맨 위의 **"M" 글자 동그라미**를 **프로필 이미지(커비 사진)** 로 바꿨어요.

- 수정한 파일: `index.html`
- 추가한 파일: `profile.png` (`index.html`과 같은 폴더에 둔 프로필 이미지)

---

## 변경 1. HTML: 글자 "M" → 이미지 태그

### Before (a)
```html
<div class="avatar" aria-hidden="true">M</div>
```

### After (b)
```html
<div class="avatar"><img src="profile.png" alt="Mandy 프로필 이미지" /></div>
```

### 설명
- 동그라미(`div.avatar`) 안에 있던 글자 `M`을 지우고, 그 자리에 `<img>` 태그를 넣었어요.
- `src="profile.png"`: 같은 폴더에 있는 `profile.png` 파일을 보여줘요.
- `alt="Mandy 프로필 이미지"`: 이미지가 안 보일 때나 화면 낭독기가 읽어줄 때 쓰이는 설명이에요.
- `aria-hidden="true"`는 지웠어요. 전에는 "M"이 꾸밈용 글자라서 화면 낭독기가 읽지 않도록 숨겼는데, 이제는 의미 있는 프로필 사진이라 읽히도록 했어요.

---

## 변경 2. CSS: 동그라미 스타일 보완 + 이미지 스타일 추가

### Before (a)
```css
.avatar {
  width: 72px;
  height: 72px;
  border-radius: 50%;
  background: var(--accent-soft);
  color: var(--accent);
  display: grid;
  place-items: center;
  font-size: 30px;
  font-weight: 800;
  margin-bottom: 20px;
}
```

### After (b)
```css
.avatar {
  width: 72px;
  height: 72px;
  border-radius: 50%;
  background: var(--accent-soft);
  color: var(--accent);
  display: grid;
  place-items: center;
  font-size: 30px;
  font-weight: 800;
  margin-bottom: 20px;
  overflow: hidden;                          /* 추가 */
  border: 3px solid var(--surface);          /* 추가 */
  box-shadow: 0 0 0 2px var(--accent-soft);  /* 추가 */
}

.avatar img {             /* 새로 추가 */
  width: 100%;
  height: 100%;
  object-fit: cover;
  display: block;
}
```

### 설명
`.avatar`(동그라미)에 3줄을 추가했어요.
| 속성 | 하는 일 |
|---|---|
| `overflow: hidden` | 동그라미 밖으로 튀어나온 사진 모서리를 잘라서, 사진이 **동그랗게** 보이게 해요. |
| `border: 3px solid var(--surface)` | 사진 둘레에 카드 배경색과 같은 얇은 테두리를 둘러요. |
| `box-shadow: 0 0 0 2px var(--accent-soft)` | 그 바깥에 연한 파란색 링을 하나 더 그려서 사진이 또렷하게 구분돼요. |

`.avatar img`(동그라미 안의 사진)는 새로 만들었어요.
| 속성 | 하는 일 |
|---|---|
| `width: 100%; height: 100%` | 사진을 동그라미 크기(72px)에 꽉 맞춰요. |
| `object-fit: cover` | 사진 비율은 그대로 두고, 남는 부분만 잘라서 찌그러지지 않게 해요. |
| `display: block` | 사진 아래에 생기는 작은 빈틈을 없애요. |

---

## 결과
- **a:** 파란 동그라미 안에 "M" 글자
- **b:** 같은 크기의 동그라미 안에 커비 사진이 꽉 차게 들어가고, 테두리가 둘러진 모습
