# 버그수정: 쿠키 하트의 글자가 하트 밖으로 튀어나온 문제

> 한 줄 요약: CSS 명령 두 개의 **순서**가 틀려서 🍪 쿠키 하트만 깨졌고, **순서만 바꿔서** 고쳤어요.

---

## 0. 먼저 알아둘 것: 웹페이지를 만드는 3가지

`index.html` 파일 하나 안에 세 가지가 함께 들어 있어요.

| | 역할 | 비유 | 파일 안 위치 |
|---|---|---|---|
| **HTML** | 무엇이 있는지 | 뼈대, 물건 | `<body>` 안의 태그들 |
| **CSS** | 어떻게 보이는지 | 옷 입히는 규칙 | `<style>` ~ `</style>` |
| **JS** | 무엇을 하는지 | 스위치, 동작 | `<script>` ~ `</script>` |

화면에 보이는 최종 모습은 브라우저가 **HTML에 CSS 옷을 입히고 JS 동작을 연결해서** 그린 결과예요.
이번 버그는 HTML(내용)은 멀쩡했고, **CSS(보여주는 규칙)** 끼리 순서가 꼬여서 생긴 문제예요.

---

## 1. 어떤 상황이었나요?

3번에서 직사각형 칸을 하트로 바꾼 직후, **첫 번째 하트(새로운 과자 사먹기)만** 이상하게 보였어요.

```
  기대한 모습            실제 모습
     🩷               🍪 새로운 과■■기   ← 하트 밖 왼쪽 위로 삐져나옴
     🍪                    🩷            ← 하트 안은 텅 빔
  새로운 과자                             ← 글자 일부가 하트에 가려짐
   사먹기
```

- 두 번째(🧱 블록 조립하기), 세 번째(🌿 자연 구경하기) 하트는 **정상**이었어요.

---

## 2. HTML: 하트 3개와 글자 상자들

`index.html` 256~277줄

```html
<ul class="likes">
  <li>
    <svg class="heart-bg">...하트 그림...</svg>
    <button class="like-content like-btn" id="snackBtn">🍪 새로운 과자 사먹기</button>
  </li>
  <li>
    <svg class="heart-bg">...하트 그림...</svg>
    <div class="like-content">🧱 블록 조립하기</div>
  </li>
  <li>
    <svg class="heart-bg">...하트 그림...</svg>
    <div class="like-content">🌿 자연 구경하기</div>
  </li>
</ul>
```

각 하트 칸(`<li>`)은 **두 겹**이에요.
- 아래 겹: `<svg class="heart-bg">` → 🩷 **하트 그림**
- 위 겹: 글자 상자 → **이모지 + 글자**

### 글자 상자의 종류: `<div>` vs `<button>`

| | `<div>` 📦 | `<button>` 🔘 |
|---|---|---|
| 뜻 | 아무 기능 없는 빈 상자 (division = 구역) | 누르는 버튼 |
| 태어날 때 모양 | 투명 | **회색 네모 옷** |
| 클릭 / 키보드(Tab → Enter) | 반응 없음 | 누를 수 있음 |
| 쓰인 곳 | 🧱 블록, 🌿 자연 (보여주기만) | 🍪 쿠키 (누르면 커비가 먹음) |

### 이름표(`class`)

`class`는 **이름표**예요. CSS는 이름표를 보고 "너는 이 옷 입어!" 하고 명령해요.
- 세 상자 모두 `like-content` 이름표 → **"하트 한가운데 앉는 옷"** 을 받아요
- 🍪 쿠키만 `like-btn` 이름표가 하나 더 → **"옷 전부 벗어!"** 명령도 받아요

---

## 3. CSS: 두 가지 명령

**👕 명령 ① `.like-content`: "하트 한가운데 앉는 옷 입어!"**

```css
.like-content {
  position: absolute;      /* 하트 그림 위에 올라가 앉기 */
  inset: 0;                /* 하트 크기에 꽉 맞추기 */
  display: flex;           /* ┐ 이모지는 위, 글자는 아래 */
  flex-direction: column;  /* │                          */
  align-items: center;     /* │ 모두 한가운데로          */
  justify-content: center; /* ┘                          */
}
```

**🙅 명령 ② `.like-btn`: "옷 전부 벗어!"**

```css
.like-btn {
  all: unset;        /* 버튼의 회색 옷을 벗기려고 썼지만, 실제로는 "모든" 스타일을 지움 */
  cursor: pointer;   /* 마우스를 올리면 손가락 모양 👆 */
}
```

---

## 4. 😵 원인: 명령 순서가 틀렸어요

CSS 규칙 두 가지만 기억하면 돼요.
1. CSS는 **위에서 아래로** 읽어요.
2. 같은 힘의 명령이 부딪히면 **나중에 쓴 명령**이 이겨요.

```css
/* ❌ 버그가 있던 순서 */

.like-content {        /* ① 먼저: 하트 옷 입어! 👕 */
  position: absolute;
  inset: 0;
  display: flex;
  ...
}

.like-btn {            /* ② 나중: 전부 벗어! 🙅  ← 이게 이김 */
  all: unset;
}
```

🍪 쿠키 버튼은 이름표가 둘 다 있어서 두 명령을 모두 받았어요. 하트 옷을 입자마자 "전부 벗어!"를 들은 거예요.

```
position: absolute  → ❌ 지워짐  (하트 위에 앉는 법을 잊음)
inset: 0            → ❌ 지워짐  (하트 크기를 잊음)
display: flex       → ❌ 지워짐  (가운데 정렬을 잊음)
```

→ 칸 왼쪽 위의 평범한 한 줄 글자가 됐고, 하트 그림(`position: absolute`)이 그 위에 그려지면서 글자를 가렸어요.

**🧱 🌿는 왜 괜찮았나?** `<div>`라서 처음부터 벗길 회색 옷이 없었어요. `like-btn` 이름표가 필요 없었으니 "전부 벗어!" 명령도 받지 않았어요.

> 💡 5살 버전: 쿠키한테 "하트 옷 입어!" 하고 바로 "옷 다 벗어!"라고 했더니, 회색 옷만 벗어야 하는데 방금 입은 하트 옷까지 다 벗어버렸어요. 그래서 어디 앉아야 하는지 잊고 구석으로 가버렸어요.

## 5. ✅ 해결: 순서만 바꿨어요

`index.html` 164~186줄

```css
/* ✅ 고친 순서 */

/* 버튼 기본 모양 지우기 (.like-content보다 먼저 써야 위치 설정이 지워지지 않아요) */
.like-btn {            /* ① 먼저: 전부 벗어! 🙅 → 회색 옷이 사라짐 */
  all: unset;
  box-sizing: border-box;
  cursor: pointer;
}

.like-content {        /* ② 나중: 하트 옷 입어! 👕 ← 이게 이김 */
  position: absolute;
  inset: 0;
  display: flex;
  ...
}
```

코드 내용은 한 글자도 바꾸지 않았어요. **위치만** 바꿨어요.

| | 순서 | 결과 |
|---|---|---|
| ❌ 버그 | 👕 입고 → 🙅 벗기 | 옷이 다 벗겨짐 → 하트 밖으로 😢 |
| ✅ 수정 | 🙅 벗고 → 👕 입기 | 회색 옷만 사라지고 하트 옷이 남음 → 하트 가운데 🍪💕 |

---

## 6. 직접 확인해 보는 방법

1. 브라우저에서 `index.html`을 열고 첫 번째 하트를 우클릭 → **검사(Inspect)**
2. 오른쪽 **Styles** 패널에서 `.like-content`와 `.like-btn`이 둘 다 적용된 것을 확인
3. 버그를 다시 보고 싶으면 `.like-btn { ... }` 블록을 `.like-content` 블록 **아래로** 옮기고 새로고침 → 첫 번째 하트만 다시 깨짐 (확인 후 원래 자리로 되돌리기)

---

## 7. 🌟 배운 점

1. **CSS는 위에서 아래로, 나중에 쓴 게 이긴다.**
2. **`all: unset`("전부 벗어")은 맨 위에, 원하는 스타일은 그 아래에.**
3. **셋 중 하나만 고장 나면, 그 하나만 다른 점부터 찾기.** 이번 범인은 "`<button>`이라서 `like-btn` 이름표가 하나 더 있었다"는 점이었어요. 🔍
