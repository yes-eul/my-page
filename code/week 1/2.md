# 2. "새로운 과자 사먹기"를 누르면 커비가 쿠키 먹기

## 무엇을 바꿨나요?
좋아하는 것 목록의 **"새로운 과자 사먹기"를 클릭**하면,
1. 🍪 쿠키가 목록에서 튀어나와 **포물선을 그리며 빙글빙글 돌면서** 프로필 커비의 입으로 날아가요.
2. 그동안 커비는 **살짝 커지며** 빨아들이는 모습이 되고, 쿠키 뒤로 **부스러기 4개**가 따라 빨려 들어가요.
3. 쿠키가 입에 닿으면 커비가 **꿀꺽(찌그러졌다 돌아오는 동작)** 하고, 옆에 **"냠냠! 🍪"** 글자가 떴다가 사라져요.

- 수정한 파일: `index.html` (HTML, CSS, JavaScript 세 군데 모두 수정)
- 이번에 처음으로 **JavaScript**(`<script>`)가 들어갔어요. 1번까지는 "보여주기"만 했다면, 이제는 "클릭에 반응하기"가 생겼어요.

---

## 변경 1. HTML: 글자 항목 → 누를 수 있는 버튼

### Before (a)
```html
<li><span class="emoji">🍪</span>새로운 과자 사먹기</li>
```

### After (b)
```html
<li class="clickable">
  <button type="button" class="like-btn" id="snackBtn">
    <span class="emoji">🍪</span>새로운 과자 사먹기
    <span class="hint">눌러보세요 👆</span>
  </button>
</li>
```

### 설명
- 항목 내용을 `<button>`으로 감쌌어요. 버튼이어야 마우스 클릭뿐 아니라 **키보드(Tab → Enter)** 로도 누를 수 있어요.
- `id="snackBtn"`: JavaScript가 "이 버튼"을 찾을 수 있도록 붙인 이름표예요.
- `<span class="hint">눌러보세요 👆</span>`: 누를 수 있다는 걸 알려주는 작은 안내 문구예요.
- 나머지 두 항목(블록 조립하기, 자연 구경하기)은 그대로예요.

---

## 변경 2. CSS: 버튼 모양 + 날아가는 쿠키 모양

### Before (a)
없음 (새로 추가한 스타일이에요)

### After (b) — `footer {` 바로 위에 추가
```css
/* 클릭할 수 있는 항목 (새로운 과자 사먹기) */
.likes li.clickable { padding: 0; }

.like-btn {
  all: unset;
  box-sizing: border-box;
  width: 100%;
  display: flex;
  align-items: center;
  gap: 14px;
  padding: 14px 16px;
  border-radius: 14px;
  cursor: pointer;
}

.like-btn:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }

.hint {
  margin-left: auto;
  font-size: 12px;
  color: var(--muted);
}

/* 커비가 쿠키를 빨아들이는 효과 */
.card { position: relative; }

.avatar { transition: transform 0.3s ease; }
.avatar.inhaling { transform: scale(1.12); }

.flying-cookie,
.crumb {
  position: fixed;
  pointer-events: none;
  z-index: 10;
  transform: translate(-50%, -50%);
}

.flying-cookie { font-size: 24px; line-height: 1; }

.crumb {
  width: 6px;
  height: 6px;
  border-radius: 50%;
  background: #c98a4b;
}

.yum {
  position: absolute;
  font-size: 14px;
  font-weight: 800;
  color: var(--accent);
  pointer-events: none;
  white-space: nowrap;
}
```

### 설명
| 코드 | 하는 일 |
|---|---|
| `.like-btn { all: unset; ... }` | 버튼의 기본 회색 모양을 전부 지우고, 다른 항목과 **똑같은 모양**으로 보이게 해요. `cursor: pointer`로 마우스를 올리면 손가락 모양이 돼요. |
| `.likes li.clickable { padding: 0; }` | 안쪽 여백은 버튼이 대신 가지도록 해서, **항목 전체 어디를 눌러도** 반응하게 해요. |
| `.like-btn:focus-visible` | 키보드로 이동했을 때 파란 테두리로 "지금 여기 있어요"를 보여줘요. |
| `.hint { margin-left: auto; }` | "눌러보세요" 문구를 오른쪽 끝으로 밀어줘요. |
| `.avatar.inhaling { transform: scale(1.12); }` | 쿠키를 빨아들이는 동안 커비를 **12% 키워요**. `transition` 덕분에 부드럽게 커져요. |
| `.flying-cookie`, `.crumb` | 날아가는 쿠키와 부스러기의 모양이에요. `position: fixed`로 화면 위를 자유롭게 날아다니고, `pointer-events: none`으로 클릭을 방해하지 않아요. 부스러기는 쿠키색(갈색) 작은 동그라미예요. |
| `.card { position: relative; }` + `.yum` | "냠냠!" 글자를 카드 안에서 커비 바로 옆에 띄우기 위한 설정이에요. |

## 변경 3. JavaScript: 클릭하면 애니메이션 실행

### Before (a)
없음 (JavaScript가 전혀 없었어요)

### After (b) — `</main>` 바로 아래에 `<script>` 추가
코드가 길어서 **흐름 위주**로 정리했어요. 전체 코드는 `index.html` 맨 아래에 있어요.

```js
snackBtn.addEventListener("click", () => {
  // ① 쿠키 출발 위치(목록의 🍪)와 도착 위치(커비 입)를 계산
  // ② 커비를 크게 만들기 (inhaling 클래스 추가)
  // ③ 쿠키 1개 + 부스러기 4개를 커비 입으로 날려 보내기 (fly 함수)
  // ④ 쿠키가 도착하면 → 커비 원래 크기로 + 꿀꺽 + "냠냠!" (gulp 함수)
});
```

### 단계별 설명
**① 위치 계산**
```js
const from = snackBtn.querySelector(".emoji").getBoundingClientRect();
const to = avatar.getBoundingClientRect();
const mouth = { x: to.left + to.width * 0.6, y: to.top + to.height * 0.62 };
```
- `getBoundingClientRect()`는 "이 요소가 지금 화면 어디에 있는지" 알려줘요.
- 프로필 사진 속 커비 입은 사진 가운데보다 살짝 오른쪽 아래(가로 60%, 세로 62%)에 있어서, 그 지점을 도착점으로 정했어요.

**② 빨아들이기 시작**
```js
avatar.classList.add("inhaling");
```
- CSS에서 만든 `.inhaling`을 붙이면 커비가 커져요.

**③ `fly` 함수: 쿠키 날리기**
```js
el.animate([
  { transform: "... scale(1) rotate(0deg)" },                 // 출발: 원래 크기
  { transform: "... scale(0.9) rotate(200deg)", offset: 0.45 }, // 중간: 위로 살짝 솟으며 회전
  { transform: "... scale(0.1) rotate(540deg)" }              // 도착: 작아지며 입속으로
], { duration, delay, easing: "cubic-bezier(.55, 0, .85, .4)" });
```
- 출발 → 중간 → 도착 세 지점을 정해 주면 브라우저가 그 사이를 자연스럽게 이어줘요.
- 중간 지점을 30px 위로 올려서 **곡선(포물선)** 으로 날아가요.
- 점점 빨라지는 속도(`cubic-bezier`)를 써서 **"훅~ 빨려 들어가는"** 느낌을 냈어요.
- 부스러기 4개는 출발 위치를 조금씩 흩뜨리고(`Math.random()`), 0.07초씩 늦게 출발시켜서 쿠키를 줄줄이 따라가게 했어요.

**④ `gulp` 함수: 꿀꺽 + 냠냠**
```js
avatar.animate([
  { transform: "scale(1.12)" },
  { transform: "scale(0.9, 1.1)" },   // 옆으로 홀쭉, 위로 길쭉
  { transform: "scale(1.08, 0.94)" }, // 옆으로 통통, 위로 납작
  { transform: "scale(1)" }           // 원래대로
], { duration: 450 });
```
- 가로/세로 비율을 번갈아 바꿔서 **말랑하게 삼키는** 느낌을 줬어요.
- 동시에 "냠냠! 🍪" 글자를 만들어서 위로 떠오르며 사라지게 했어요.

**+ 움직임 줄이기 설정 배려**
```js
const reduceMotion = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
```
- 기기에서 "동작 줄이기"를 켠 사람에게는 날아가는 효과 없이 **"냠냠!"만** 보여줘요.

---

## 결과
- **a:** "새로운 과자 사먹기"는 그냥 글자라서 눌러도 아무 일이 없음
- **b:** 누르면 쿠키와 부스러기가 커비 입으로 빨려 들어가고, 커비가 꿀꺽 삼킨 뒤 "냠냠! 🍪"이 뜸
